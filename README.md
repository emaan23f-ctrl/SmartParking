# SmartParking

SmartParking is a static parking reservation website for finding and booking nearby parking spaces.

## Features

- Browse available and occupied parking spots on an interactive layout
- Search parking spots by location
- Select hourly or daily booking options
- Save bookings in the browser with `localStorage`
- View existing bookings from the navigation bar
- Toggle between light and dark themes
- Explore customer, parking owner, and contact pages

## Pages

- `index.html` - Landing page and interactive parking layout
- `choose-parking.html` - Parking spot search and selection
- `booking.html` - Booking form
- `parking.html` - Parking owner information
- `about.html` - About SmartParking
- `contact us.html` - Contact page

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome icons via CDN
- Browser `localStorage` for demo bookings and theme preferences
